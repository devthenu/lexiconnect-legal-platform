# Archive

This folder stores legacy or non-runtime artifacts kept for historical/reference purposes.

Archived items include:
- legacy/duplicate folders (`LexiConnect/`, `src/`)
- exported artifacts (`ReleaseNotes.html`, `LexiConnect_Final_Report.pdf`)
- legacy root compose file (`docker-compose.root.legacy.yml`)
- superseded root docs moved out of the main operating surface

Nothing in this folder is required for current build/runtime/deploy.
